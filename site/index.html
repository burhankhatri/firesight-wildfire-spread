FireSight: predicting where a wildfire burns tomorrow

Google Earth Engine satellite and weather data for 18,545 real fires, 24 physics-informed features, five tuned machine learning models, and an interactive digital twin that shows how wind and climate warming change tomorrow's fire.

Try the digital twin Research paper (PDF) Slides (PDF) Code on GitHub

The problem

Satellites already show where fires are burning today. Firefighters need to know where they will be tomorrow. Given today's fire and 11 environmental layers for a 64 km × 64 km area at 1 km resolution, we predict which square kilometres will be burning the next day.

Method

The original dataset paper treated this as image segmentation. We turned every pixel into a row and gave the models the spatial and physical context they otherwise never see.

GEE dataMODIS fire, VIIRS NDVI, SRTM, GRIDMET weather & drought, population
PreprocessDrop cloud-masked labels, clip outliers, impute, standardize
EngineerFire density, distance to fire, upwind fire, wind vectors, slope, dryness
Model & tuneLR, RF, XGBoost, LightGBM, MLP with grouped CV search
Explain & simulateSHAP drivers + wind / warming digital twin

Results

All scores are on 6.7 million unseen test pixels at the real fire rate. The threshold for each model was picked on a separate validation split.

Digital twin: what if the wind changes, or the climate warms?

Pick a real test fire, then change the conditions. Every feature is recomputed from the changed inputs and the trained model predicts tomorrow's fire again.

Run it anywhere with Google Earth Engine

The repository includes a GEE script that builds the same 12 input layers for any place and day. Outside the US it swaps GRIDMET for ERA5-Land and TerraClimate. The example is set to the Margalla Hills near Islamabad, Pakistan.

Dataset: Next Day Wildfire Spread (Huot et al., IEEE TGRS 2022), built in Google Earth Engine. CC BY 4.0.
